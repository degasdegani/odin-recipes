# Odin Recipes

A basic recipe website built with plain HTML, as part of The Odin Project Foundations course.

## About

The site has a home page that links to a few recipe pages. Each recipe page has an image, a description, a list of ingredients and the steps to prepare the dish.

This project has no styling yet. CSS will be added in a later part of the course.

## Skills demonstrated

- HTML boilerplate and document structure
- Headings, paragraphs and lists
- Links between pages using relative paths
- Images with `alt` text
- Git and GitHub workflow with clear commit messages
